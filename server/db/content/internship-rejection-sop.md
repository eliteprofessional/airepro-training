# Internship Rejection SOP (Intern → Freelancer)

**SOP-INT-003**

## Purpose

Reject a conversion request with a clear reason. After reject, the intern can re-request if still eligible (no open pending/approved row).

## When to use

Pending conversion should not proceed (policy, incomplete profile, suspected abuse, etc.).

## Step 1 — Select reject

### Check

- Rejection reason **required** in OBO UI
- Notes optional but useful for audit

### Expected result

Request `rejected`; user remains intern.

## Step 2 — Communicate

### Check

- Customer-facing explanation matches reason (no unnecessary PII)
- Remediable issues stated clearly if they may re-request

### Expected result

Intern understands whether they can try again later.

## DO

- Always record rejection reason
- Allow re-request when policy allows

## DON'T

- Reject without reason
- Approve then try to “undo” via reject

## Escalate when

- Suspected fraud / fake hire behind the conversion
- Repeated gaming of eligibility
