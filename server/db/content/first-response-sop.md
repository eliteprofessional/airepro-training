# First Response SOP

**SOP-SUP-001**

## Purpose

Acknowledge the customer quickly and set accurate expectations.

## When to use

New ticket / message / contact in Support queues.

## Step 1 — Acknowledge

### Check

- Restate the issue in your words
- Confirm key IDs if already provided (user email may already be on the ticket — do not ask for PAN/Aadhaar)

### Expected result

Customer knows someone is working it.

## Step 2 — Set next update

### Check

- Give a realistic next-update window based on published Support guidance (if none, say you will update after investigation — do not invent SLA hours)

### Expected result

Expectation set without over-promising.

## Step 3 — Start investigation

### Check

- Map to IDV / Payments / Account / Jobs using Knowledge Base
- Use internal notes for system findings

### Expected result

Ticket moves to In progress with a plan.

## DO

- Be clear and respectful
- Prefer links to Hire Support articles for how-to when appropriate

## DON'T

- Ask for passwords or full ID images in chat
- Blame the customer

## Escalate when

- Safety / fraud / payment mismatch requiring specialist queues
