# Ticket Closure SOP

**SOP-SUP-003**

## Purpose

Close tickets only when the issue is resolved, declined per policy, or abandoned per Support rules.

## When to use

Resolution delivered or no further action possible.

## Step 1 — Confirm resolution

### Check

- Customer confirmed when required by your queue rules
- Related payment/IDV case closed or explicitly handed off

### Expected result

Clear resolution note with outcome.

## Step 2 — Close

### Check

- Native status set to Resolved/Closed (use UI labels)
- No open escalation without owner

### Expected result

Ticket closed; reopen path documented if policy allows.

## DO

- Record what fixed it (for search analytics later)
- Link related SOP used

## DON'T

- Close while waiting on payments reconciliation without noting owner
- Delete history

## Escalate when

- Customer disputes closure with new evidence
- Safety issue discovered at closure time
