# SOP guidelines

Use the template:

1. Purpose  
2. When to use  
3. Before you start  
4. Numbered steps with **Check** / **Expected result**  
5. DO / DON'T  
6. Escalate when  
7. Related SOPs  
8. Version  

Always mark unreviewed content as training placeholders. Prefer synthetic examples — never paste production customer PII into training bodies.

Maker ≠ Approver for sensitive procedures is a process requirement (workflow UI for IN_REVIEW → PUBLISHED is available via status field; strict maker-checker enforcement is Phase 9+ hardening).
